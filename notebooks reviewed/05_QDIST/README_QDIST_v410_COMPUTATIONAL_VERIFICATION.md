# QDIST v4.1 computational verification revision

This package consumes the already completed `qdist_v410_candidate_cohort` run. It does not rerun 519 recordings and does not require manual reviewers.

It verifies the completed source artifact hashes, re-evaluates the 144 exact-mask speech interventions with uncertainty, audits all 80 signal-evidence items against governed ledgers, assigns final feature-level decisions, and builds a self-contained revised A–J figure suite. Panels I, J, and G are corrected so they no longer state that two reviewers are required.

The output is written to:

`outputs reviewed/nonlinear_distortion/qdist_v410_candidate_cohort/computational_verification_v1`

No feature values, detector parameters, or thresholds are changed. Publication freeze remains disabled until cross-family arbitration and manuscript reconciliation are complete.
