# QGAIN v4.1.0 standardized validation and figure-completion contract

- Measurement freeze: `qgain-v4.1.0` (immutable; never modified).
- Figure supplement: `qgain-v4.1.0-figures-v1.0.0`.
- Required panels: A–H. Panel I is not applicable because QGAIN has no retained event detector. Panel J is included for the quality-aware ML handoff.
- Every standardized figure requires PNG (300 dpi), SVG, PDF, source CSV, Markdown caption, and JSON provenance.
- The supplement may read frozen tables and ledgers but must not decode audio, recompute feature values, construct a family scalar, or calibrate a generic accept/reject threshold.
- The completed family workbook and machine-readable checklist must be included in the sealed supplement.
- Any future change requires a new figure-package semantic version and may not overwrite this package.
