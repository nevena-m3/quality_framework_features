# QGAIN v4.1.0 standardized validation and figure package

This package completes the common family-evaluation template for the frozen QGAIN measurement family.

## Scientific status

- Measurement family: `qgain-v4.1.0` — frozen.
- Figure supplement: `qgain-v4.1.0-figures-v1.0.0` — complete reference package.
- Frozen cohort: 519 recordings from 224 participants.
- Required panels A–H: complete.
- Event panel I: not applicable because QGAIN has no retained event detector.
- Optional panel J: complete for the quality-aware ML handoff.
- Feature values were not recomputed or modified.
- No family scalar or standalone recording-rejection threshold is authorized.

## Contents

- Completed Word family evaluation workbook.
- Ten-domain validation dashboard.
- Detailed G1–G10 machine-readable checklist.
- 32 indexed scientific figures.
- PNG (300 dpi), SVG, and PDF for each figure.
- One source-data CSV, caption, and provenance JSON per figure.
- Eight deterministic signal-linked examples from frozen frame and segment ledgers.
- Legacy QGAIN galleries retained as supplementary audit evidence.
- Package manifest and SHA-256 artifact inventory.

## Interpretation

QGAIN measures recorded operating level and level dynamics. It cannot identify whether a natural change arose from device gain, microphone distance, automatic level control, speaker intensity, respiratory control, prosody, dysarthria, fatigue, or task structure. The completed package treats this non-identifiability as an explicit claim boundary.
