# QDIST v3.1.1 release notes

This release adds a validated exact-signed-PCM-rail pathway for plateaus of at least three native samples while retaining the stricter quantization-aware repeated-level contract for unknown sub-rail saturation. It adds exact-rail duration calibration, near-rail negative controls, acquisition-vintage stratification, prevalence-aware repeated-recording metrics, and a randomized blinded review package with a concealed answer key. All outputs, checkpoints, hashes, and freeze paths use qdist-v3.1.1.
